# Approval Workflow Example

This folder contains a small, checked-in example of the main artifact chain:

- `source_manifest.json`
- `target_manifest.json`
- `manifest_diff.json`
- `plan.json`
- `approval.json`
- `state.json`
- `verification_report.json`
- `post_migration_summary.md`

The values are intentionally small and reviewable. They show the shape of the workflow without requiring a live database.
